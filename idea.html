Where does AI help?

  1. Read evidence: the vision API reads bills and receipts into amount, currency and source text.
  2. Cache the facts: unchanged images and context do not need another API call.
  3. Calculate: Python forecasts expenses and tests payment options against the reserve and deadline.
  4. Explain: show the chosen schedule and the facts that support it.

The real solution also handles pending debits, dated exchange rates, partial payments, offered installments and protected spending. An uncertain image is retried with a stronger model and flagged if it still cannot be read.
